# Maison Élise Bridge

Intégration Home Assistant dédiée à la passerelle Alexa de Maison Élise.

Ce dépôt est séparé d’Élise Investigator afin que les cycles de version HACS du Bridge et les versions de développement d’Investigator restent indépendants.

## Version de référence

La base fonctionnelle reprise est **0.1.0-dev.8**, issue du commit `3e03138b19926be37de14d62a1f2f9a7d30f0181` de l’ancien dépôt `brunofoxmulder/elise-investigator`.

## Sécurité de migration

La création de ce dépôt ne modifie pas l’installation Home Assistant existante, le Cloudhook ni la Lambda Alexa. La migration HACS doit être effectuée séparément après validation.
